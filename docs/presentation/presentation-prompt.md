# RedGrid Presentation — Master Prompt for AI Slide Generator

## Meta Instructions for the Slide Agent

Generate a **10-minute MSc thesis inception-stage presentation** (20 slides total) for the project **RedGrid: Dependency-Constrained UCB Exploration for Autonomous Penetration Testing**. The presentation is the first submission in a 6-month thesis program. The report is complete for Chapters 0, 1, and 2 only (Introduction + Literature Review). Methodology, evaluation, and results are not yet done. The presentation must:

- **Deeply cover Chapters 1 and 2** (slides 1–11: problem, background, literature, gap analysis)
- **Transition slide** (slide 12: expected contributions — marks the shift from deep to sketch)
- **Give high-level visual overviews** of remaining chapters (slides 13–19: architecture, methodology sketch, evaluation plan, timeline, challenges, summary)
- **Closing** (slide 20: thank you / Q&A)
- Be honest about early-stage work while sounding polished, confident, and research-grade
- Feel **professional, catchy, and visually alive** — not a wall of text
- Be suitable for a **10-minute slot** (~30–40 sec per slide for early slides, 45–60 sec for architecture slides)

## Theme and Visual Design System

> **Design Philosophy:** This presentation must feel like it was hand-crafted by a careful human researcher — not generated by an AI template engine. Every design decision is deliberate, minimal, and serves communication. Avoid any element that looks "stock", generic, or decorative without purpose.

### Color Palette

**Primary Palette:**
- **Slide background:** `#F7F4EF` — warm off-white (like high-quality matte paper; NOT pure `#FFFFFF`)
- **Slide surface (card/panel):** `#EFEBE3` — slightly deeper warm cream for inset panels
- **Primary text (body, bullets):** `#1A1A2E` — deep ink navy (not pure black; softer on eye under projection)
- **Secondary text (captions, footnotes, sub-labels):** `#6B6B7A` — muted slate grey
- **Tertiary text (metadata, timestamps, slide numbers):** `#9A9AAA` — lighter cool grey

**Accent Palette (use sparingly — max 1–2 accents visible per slide):**
- **Primary accent — Crimson:** `#8B1A1A` — deep academic red (think: red wax seal, not neon; signals danger, attack, urgency without being garish)
- **Secondary accent — Slate Blue:** `#2E4A7A` — dark academic blue (for data, exploration, technical callouts; calm and trustworthy)
- **Tertiary accent — Warm Amber:** `#A0631A` — muted amber-brown (for highlights, status chips, secondary callouts; earthy, not fluorescent)
- **Positive signal:** `#2A6B3C` — dark forest green (for DONE/SUCCESS/EXPLOITED states)
- **Caution signal:** `#7A4F1A` — dark burnt amber (for WARNING/UP NEXT/INFERRED states)
- **Blocked signal:** `#7A1A1A` — dark muted crimson (for BLOCKED/INFEASIBLE/FAILED states)

**Structural Colors:**
- **Dividers / hairlines:** `#D4CFC8` — warm light grey (barely visible; adds structure without noise)
- **Table header background:** `#E8E4DC` — slightly darker warm cream
- **Table alternating row:** `#F3F0EA` — near-background, subtle stripe
- **Callout box background:** `#EDE9E1` — warm cream card
- **Highlight strip (inline):** `#E8DDD0` — very light warm tan (for inline key-term highlighting)

**Color Usage Rules:**
1. Never use more than ONE primary accent color as the dominant element on a slide.
2. The crimson accent is reserved for: the title wordmark, left-border callout bars, critical warnings, and the "RedGrid" project name.
3. Slate blue is reserved for: data elements, chart lines, technical annotation, exploration-related visual cues.
4. Amber/warm tones are reserved for: status chips, secondary callout boxes, timeline "UP NEXT" states.
5. Green/red node colors (VDG diagram, Slide 10) are the ONLY place both red and green appear on the same slide — and only inside the diagram boundary.
6. All accent usage must pass WCAG AA contrast against `#F7F4EF` background.

### Typography

**Font Stack:**
- **Display / Title font:** `"Playfair Display"` (Google Fonts) — elegant serif. Weight 700 for slide titles, 400 italic for pull-quotes. Conveys academic gravitas and hand-crafted quality. Falls back to `Georgia, serif`.
- **Heading / Sub-heading font:** `"Source Sans 3"` (Google Fonts, formerly Source Sans Pro) — neutral, clean sans-serif for section headings, card titles, labels. Weight 600. Falls back to `system-ui, sans-serif`.
- **Body / Bullet font:** `"Source Sans 3"` — Weight 400 for body, 600 for bold-lead bullet starters.
- **Monospace / Data font:** `"IBM Plex Mono"` (Google Fonts) — for node labels, metric values in charts, code-adjacent content, slide numbers. Falls back to `monospace`.
- **Caption / Meta font:** `"Source Sans 3"` — Weight 400 italic for captions and speaker-attribution notes.

**Font Sizes (in a 16:9 slide at 1920×1080px reference resolution):**
- Slide title: **42–46pt** in Playfair Display 700
- Section / Card heading: **22–26pt** in Source Sans 3 600
- Body text / bullets: **19–21pt** in Source Sans 3 400
- Captions / footnotes: **13–15pt** in Source Sans 3 400 italic, color `#6B6B7A`
- Data labels / chart callouts: **14–16pt** in IBM Plex Mono 400
- Slide number: **13pt** in IBM Plex Mono 400, color `#9A9AAA`
- Inline key-term bold: **same pt as body**, Source Sans 3 **700** (bold lead-in technique: "**Key Term:** explanation sentence")
- Pull-quote / major statement: **28–34pt** in Playfair Display 400 italic

**Typography Rules:**
1. Slide titles use Playfair Display in Title Case (NOT all-caps). Exception: the metadata label line above a title uses Source Sans 3 in tracked SMALL CAPS (letter-spacing: 0.12em).
2. Body bullets follow the bold lead-in pattern: `**Term:** Explanation sentence.` — the term is Source Sans 3 700, the rest is 400.
3. No underlines. No italics on body text except captions and pull-quotes.
4. Line height: 1.5× for body bullets; 1.2× for titles; 1.6× for long paragraph text.
5. Maximum 5 lines of body text per text column. If more is needed, use two columns or split the slide.
6. Letter-spacing (tracking): 0 for body; +0.05em for sub-headings; +0.12em for small-caps metadata labels.

**Font Embedding:**
Embed all fonts locally in the PPTX/export package. Do NOT link to Google Fonts CDN at runtime. Download and embed as embedded fonts in the PPTX or as local @font-face in HTML export.

### Layout and Spacing

**Canvas:**
- **Aspect ratio:** 16:9 (standard widescreen)
- **Reference resolution:** 1920 × 1080px (or equivalent 33.87 × 19.05 cm at 144dpi)
- **Safe area / content margin:** 80px left/right, 60px top, 70px bottom — all content must stay within this safe area
- **Gutter (column gap):** 40px between columns
- **Grid:** 12-column soft grid, 8px base unit

**Header Zone (ALL content slides — Slides 2–19):**
- **Top-left:** Slide title in Playfair Display 700, 42–46pt, color `#1A1A2E`
- **Directly below title:** A 3px horizontal rule, color `#8B1A1A` (crimson), spanning from left margin to 55% of slide width. This is the signature structural element — the "authority bar".
- **Top-right corner (all content slides except title and thank-you):** University / institution logo, height 44px, positioned 24px from top edge and 80px from right edge. Monochrome version (deep ink navy `#1A1A2E` fill). If no institutional logo is available, substitute a compact "RedGrid" wordmark in Playfair Display 700 18pt crimson.
- **Metadata label (above title on select slides):** Small-caps Source Sans 3 11pt, color `#9A9AAA`, letter-spacing 0.12em. Example: `MSc Thesis  ·  Inception Stage  ·  Sep 2026`

**Footer Zone (ALL content slides — Slides 2–19):**
- **Bottom-left:** `RedGrid` wordmark — Playfair Display 700 11pt, color `#8B1A1A` (crimson). This is the watermark — not a full logo, just the project name.
- **Bottom-center:** Thin 1px hairline `#D4CFC8`, spanning full width, 20px above bottom margin edge.
- **Bottom-right:** Slide number in format `02 / 20` — IBM Plex Mono 13pt, color `#9A9AAA`.
- **Footer total height:** 36px from bottom edge of slide.

**Layout Variants (per-slide specification overrides which variant to use):**

1. **Full Statement (S-TYPE):** No columns. Large pull-quote or bold statement centered with left-accent bar. Used for: gap statement, key finding, transition slides.
2. **Left-Heavy Two-Column (L-TYPE):** Left 60% text/content + Right 40% visual. Used for: motivation, failure mode slides.
3. **Right-Heavy Two-Column (R-TYPE):** Left 40% visual + Right 60% content. Used for: introducing-redgrid slide.
4. **Even Two-Column (E-TYPE):** 50/50 split. Used for: comparative analysis, where-we-are status slide.
5. **Card Grid (C-TYPE):** Equal-width cards in horizontal row or 2×2 grid. Used for: literature scope, contributions, challenges, objectives.
6. **Data-Focus (D-TYPE):** Full-width table or chart. Used for: comparative analysis table, waterfall chart, bar chart slides.
7. **Visual-Stack (V-TYPE):** Layered visual element dominates slide body (70% height). Used for: architecture stack, process loop.
8. **Title Slide (T-TYPE):** Special rules — see Slide 01 specification.
9. **Closing Slide (Q-TYPE):** Special rules — see Slide 20 specification.

**Callout Box System:**
- **Primary callout (crimson border):** Left 3px solid `#8B1A1A` border + `#EDE9E1` background fill. Used for key research statements, gaps, and warnings.
- **Secondary callout (slate blue border):** Left 3px solid `#2E4A7A` border + `#E8EDF5` background fill. Used for technical insight boxes, data-point callouts.
- **Tertiary callout (amber border):** Left 3px solid `#A0631A` border + `#F2EAD9` background fill. Used for transition banners, status notes, timeline notes.
- **Neutral callout (grey border):** Left 3px solid `#9A9AAA` border + `#EFEBE3` background fill. Used for speaker notes placeholders and committee questions.
- All callout boxes: padding 16px 20px, border-radius 3px (very slight rounding — not pill-shaped).

**Spacing Rules:**
1. Minimum 24px vertical space between any two content blocks.
2. Minimum 16px padding inside any card/box.
3. Icon-to-text gap: 12px.
4. List item line-height: 1.5× body font size.
5. No element should touch the authority bar (leave 20px below it before content begins).

### Chart and Diagram Design System

**Bar Charts:**
- Bars: `#8B1A1A` (crimson) for primary data series; `#2E4A7A` (slate blue) for secondary.
- Bar width: generous (60–70% of bar slot width) — not thin slivers.
- No 3D effects. Flat, crisp rectangles.
- Axis lines: 1.5px `#D4CFC8` hairline. No gridlines (except a single reference line if critical).
- Data labels: on bar (right-end or inside), IBM Plex Mono 14pt `#1A1A2E`.
- Reference line (if needed): dashed 1px `#A0631A` with text label in Source Sans 3 12pt `#A0631A`.
- Chart background: `#F7F4EF` (same as slide, no box border around chart).
- X/Y axis labels: Source Sans 3 400 13pt `#6B6B7A`.

**Waterfall Charts:**
- Same as bar chart rules.
- Positive increment bars: `#2A6B3C` (dark green).
- Baseline/total bar: `#8B1A1A` (crimson).
- Connector lines between bars: 1px dashed `#D4CFC8`.
- Key highlight bar (e.g., +0.14 ADM): amber `#A0631A` fill + ★ symbol annotation.

**Diagram / Node-Graph:**
- Node shape: Rounded rectangle, border-radius 6px. Border 1.5px.
- Node background and border colors encode status — but ALWAYS paired with a text label inside the node.
- Arrow/edge: 1.5px solid `#6B6B7A`, arrowhead filled matching line color, length proportionate to diagram.
- Node font: IBM Plex Mono 14pt for node labels; Source Sans 3 12pt for edge labels.
- Diagram background: no box, transparent on slide background.

**Process Loop Diagrams:**
- Circle segments or step boxes connected with arrows.
- Each step colored distinctly (crimson, slate blue, amber, green) — but also labeled with text and number.
- Step box: rounded rectangle 8px radius, 2px solid border matching fill color, fill at 15% opacity of that color.
- Center label: Playfair Display 400 italic 18pt `#1A1A2E`.

**Timeline:**
- Horizontal rail: 3px solid `#D4CFC8`.
- Phase segment: filled rectangle above rail, height 20px, colored per status.
- Phase dot: 12px circle at phase boundary, filled per status.
- Phase label: Source Sans 3 600 15pt above each segment.
- Status badge: Source Sans 3 600 11pt, all-caps, padded 4px 8px, border-radius 3px. Color matches phase status.

## Slide-by-Slide Specification

> **Chapter mapping:** Chapter 0 (abstract, front-matter, and framing) maps to **Slide 2 (Motivation Hook)** — the "why this matters" framing slide covers the same ground as the abstract. Chapter 1 (Introduction) maps to **Slides 2–12** — it provides the framing and motivation across the full first half of the deck. Chapter 2 (Literature Review) maps to **Slides 3–9** — these slides sit *inside* the Chapter 1 range because the introduction and literature review are interleaved in the report: the intro motivates, the lit review provides evidence, and together they build to the gap statement on Slide 9. Slides 3–9 are simultaneously Ch.1 material (introduction narrative) and Ch.2 material (evidence from surveyed papers). The architecture, methodology, evaluation, and timeline sections (Slides 13–19) are high-level sketches only — those chapters are not yet written.
