\addtotoc{Abstract}
\begin{abstract}
\addtocontents{toc}{}

\hspace{1cm} Autonomous penetration testing agents powered by large language models have shown rapid progress in recent years, yet published evaluations consistently point to two unresolved weaknesses: agents explore candidate vulnerabilities too narrowly, and they struggle to reason about the prerequisite relationships between different stages of an attack. These weaknesses limit how far current systems can be trusted to operate against realistic, multi-step web, API, and network targets without close human supervision.

\vspace{0.3cm}
\hspace{1cm} This thesis is an early-stage investigation into whether explicitly modeling the dependencies between attack steps -- rather than treating candidate vulnerabilities as an unordered list -- can improve how autonomous agents explore and prioritize their actions during a penetration test. As a first step, we conducted a systematic review of the recent literature on LLM-based offensive security agents, spanning web application exploitation, GraphQL API testing, and multi-host network attacks, to identify recurring architectural patterns, common failure modes, and the benchmarks used to evaluate such systems. Building on this review, we have begun drafting an initial system architecture intended to structure how an agent accumulates knowledge about a target and decides which attack path to pursue next.

\vspace{0.3cm}
\hspace{1cm} At this stage, our contribution is preliminary: a consolidated view of the current state of autonomous penetration testing research and an early architectural direction motivated by the gaps observed in it. The remaining work over the coming months will focus on refining this architecture, implementing it, and evaluating it against established benchmarks to determine whether dependency-aware exploration meaningfully improves exploitation performance over existing approaches.

\end{abstract}
