\section{Performance Metrics}
\label{sec_performance_metrics}

Performance evaluation is a critical aspect of assessing the efficiency and effectiveness of DataLex, an AI-enhanced SIEM system integrating LLaMA 3-based Retrieval-Augmented Generation (RAG) with traditional security event management tools. This section presents a comprehensive analysis of the system's performance metrics across multiple hardware configurations, specifically evaluating inference time, retrieval latency, memory utilization, throughput, and token generation rate.

By benchmarking against different NVIDIA GPU models and a CPU-only baseline, this study provides insights into how hardware acceleration impacts system performance. The evaluation focuses on key performance indicators (KPIs) relevant to SIEM operations, ensuring the system's reliability, speed, and accuracy in handling security events.

\subsection{Performance Evaluation Methodology}
\label{subsec_performance_evaluation_methodology}

To measure system performance, we employed a structured benchmarking process, evaluating the following metrics:

\begin{itemize}
    \item \textbf{Inference Time} -- Measures the time taken by the AI model to generate a response.
    \item \textbf{Retrieval Latency} -- Evaluates the delay in fetching security logs from the FAISS vector database.
    \item \textbf{Memory Usage} -- Tracks the RAM utilization across different processing conditions.
    \item \textbf{Throughput} -- Quantifies the number of queries processed per minute.
    \item \textbf{Token Generation Rate} -- Measures the number of tokens produced per second during AI-based analysis.
\end{itemize}

The performance tests were conducted across four hardware configurations:

\begin{itemize}
    \item CPU-only (Baseline)
    \item NVIDIA RTX 3090 (24GB VRAM)
    \item NVIDIA A100 (40GB VRAM)
    \item NVIDIA H100 (80GB VRAM)
\end{itemize}

Each configuration was subjected to a series of structured test cases designed to assess real-time performance, load handling, and efficiency in processing security events.

\subsubsection{Throughput}
\label{subsubsec_throughput}

Throughput measures the number of security queries a system can handle per minute, impacting its ability to process multiple simultaneous threat analysis requests. A CPU-only setup handles 2.45 queries per minute, which can struggle under heavy loads. However, NVIDIA RTX 3090 boosts throughput to 12.25 queries per minute, while the NVIDIA A100 increases it further to 24.50 queries per minute, providing better scalability. The NVIDIA H100 achieves the highest throughput of 36.75 queries per minute, enabling efficient real-time analysis and faster response times in high-demand environments. \reffig{fig:throughput} depicts the results clearly.

\subsubsection{Token Generation Rate}
\label{subsubsec_token_generation_rate}

Token generation rate determines the speed at which the AI model produces security insights in response to analyst queries. In this project, we measured the token generation rate using different hardware configurations to assess the speed at which the AI model produces security insights in response to analyst queries. The results show that the CPU-only configuration generated 8.72 tokens per second, while the NVIDIA RTX 3090 increased the rate to 43.60 tokens per second. The NVIDIA A100 further improved the rate to 87.20 tokens per second, and the NVIDIA H100 achieved the highest rate of 130.80 tokens per second, demonstrating a significant performance boost with GPU acceleration.

\subsection{System Resource Monitoring Commands}
\label{subsec_system_resource_monitoring_commands}

Below are the commands used for monitoring system resources:

\begin{itemize}
    \item \textbf{\texttt{htop} -- Monitor CPU / Memory Usage}
    \begin{enumerate}
        \item[a.] Used to observe real-time CPU and memory utilization across different hardware configurations.
        \item[b.] On GPU-accelerated setups, CPU usage remained at 65 percent, compared to 85 percent on CPU-only systems.
        \item[c.] Command: \texttt{htop}
    \end{enumerate}
    \item \textbf{\texttt{iostat -dx 5} -- Disk I/O Performance Monitoring}
    \begin{enumerate}
        \item[a.] Used to measure disk utilization and identify performance bottlenecks.
        \item[b.] SSD utilization reduced from 80 percent (CPU-only) to 72 percent (GPU-accelerated) due to efficient data processing.
        \item[c.] Command: \texttt{iostat -dx 5}
    \end{enumerate}
    \item \textbf{\texttt{nvidia-smi} -- GPU Utilization Monitoring}
    \begin{enumerate}
        \item[a.] Used to track GPU usage and memory allocation during AI processing.
        \item[b.] Peak GPU utilization was 70 percent on NVIDIA RTX 3090 and 55 percent on NVIDIA H100, demonstrating effective load balancing.
        \item[c.] Command: \texttt{nvidia-smi}
    \end{enumerate}
\end{itemize}
