\section{Key Contributions}
\label{sec_key_contributions}

The DataLex project introduces groundbreaking innovations to the field of cybersecurity, contributing to the research domain in several significant ways:

\begin{itemize}
    \item \textbf{Offline Generative AI-Powered SIEM}: Development of the first-ever SIEM system powered by generative AI that operates entirely offline, ensuring data sovereignty and privacy.
    \item \textbf{Explainable Threat Detection}: A novel approach to enhance threat detection by leveraging explainable AI, making security insights more accessible and actionable for security professionals.
    \item \textbf{Large Language Models for Security Analysis}: Application of large language models (e.g., LLAMA 3.0) to perform advanced security incident analysis and threat intelligence.
    \item \textbf{Privacy-Preserving Architecture}: Creation of an architecture that ensures privacy while incorporating generative AI and threat intelligence, addressing modern data protection challenges.
\end{itemize}
