\section{Thesis Organization}
\label{sec_thesis_organization}

The following outline provides a structural overview of the project: Chapter~\ref{chapter_related_works} (Related Works) explores existing research on SIEM solutions, intrusion detection systems, and AI-driven security analytics, identifying gaps that DataLex addresses. Chapter~\ref{chapter_proposed_methodologies} (Proposed Methodologies) details the system architecture, integration strategies, and the application of Generative AI for threat detection. Chapter~\ref{chapter_performance_evaluation} (Performance Evaluation) presents benchmarking results, analyzing system efficiency in log retrieval, inference time, and security event processing. Chapter~\ref{chapter_conclusions} (Conclusion) summarizes the research contributions, discusses key findings, and suggests potential improvements for Generative-AI integrated SIEM solutions in the future.
