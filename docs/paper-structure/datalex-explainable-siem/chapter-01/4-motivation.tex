\section{Motivation and Research Needs}
\label{sec_motivation}

The impetus for DataLex derives from a critical analysis of current SIEM limitations and the increasing promise of generative AI technology. Traditional security monitoring systems have reached a technical inflection point.

Cyber threats are becoming more complex, attack tactics are becoming more sophisticated, computational needs for complete threat analysis are increasing, and security mechanisms need to be more intelligent and adaptive.

DataLex tackles several systemic issues by incorporating an offline, open-source large language model into the SIEM framework:

\begin{itemize}
    \item Providing transparent, understandable threat intelligence
    \item Removing privacy risks related to external API dependencies
    \item Enabling natural language interaction with security event data
    \item Developing a flexible, adaptive threat detection mechanism
\end{itemize}
