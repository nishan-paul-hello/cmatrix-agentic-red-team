\begin{abstract}
\addtocontents{toc}{}

\hspace{1cm} DataLex represents an innovative Security Information and Event Management (SIEM) solution leveraging offline generative AI to address contemporary cybersecurity challenges. By integrating an advanced language model (LLAMA 3.0) with sophisticated correlation algorithms, the system provides comprehensive threat detection and analysis across diverse technological ecosystems, including national infrastructure, financial technology, healthcare, and urban systems.

\vspace{0.3cm}
\hspace{1cm} The research introduces a groundbreaking privacy-preserving framework operating entirely offline, eliminating external data transmission risks. Key innovations include zero external API reliance, localized event processing, and transparent AI decision-making. The methodology encompasses developing an offline generative AI architecture, creating an interpretable security analysis approach, and rigorously validating system performance.

\vspace{0.3cm}
\hspace{1cm} DataLex's primary contributions include the first offline, generative AI-powered SIEM system, a novel explainable AI threat detection methodology, and a privacy-centric threat intelligence architecture. By addressing systemic limitations of existing technologies -- such as excessive false positives and limited contextual understanding -- the project advances cybersecurity research and offers a robust solution for organizations seeking comprehensive, privacy-focused threat monitoring.

\end{abstract}
